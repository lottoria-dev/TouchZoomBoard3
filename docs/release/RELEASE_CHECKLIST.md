## 디자인과 입력

- [ ] 패널 농도 0%에서 버튼만 표시
- [ ] 패널 농도 100%에서도 배경이 선명하게 보임
- [ ] 검은 네 귀퉁이와 거친 외곽선 없음
- [ ] 아이콘과 정보창 링크 선명
- [ ] 다크·라이트 배경에서 트레이 메뉴 판독 가능
- [ ] 제조사·감마·해상도·주사율이 다른 두 화면에서 대각선 패널 밴딩 없음
- [ ] 6개 파스텔 굴절광과 사용자 지정 색 저장·재시작 복원
- [ ] 굴절광이 패널의 옅은 표면색·방향성 가장자리·버튼에서 구분되면서 배경 선명도를 해치지 않음
- [ ] 전자칠판 TouchUp, 팝업, 툴팁, 커서 정상
- [ ] 프레젠터 포커스 유지
