# 저작권·라이선스 검토 기록

## 3.0.2 정식판 확인 결과

- 새 외부 라이브러리, NuGet 패키지, 글꼴, 음원, 이미지 또는 아이콘 세트를 추가하지 않음
- Windows Magnification API와 .NET Framework의 운영체제 설치 구성요소만 호출함
- 프로그램 아이콘은 프로젝트에서 작성한 문서·돋보기 도형으로 생성함
- 패널 아이콘과 미니맵 외형은 WPF 도형 코드로 직접 작성함
- ZoomIt, Apple, GeoGebra의 코드·아이콘·로고·스크린샷·음원·UI 자산을 포함하지 않음
- GeoGebra와 브라우저는 별도 실행 프로그램에 입력을 전달하는 호환 대상으로만 언급함
- 필기 보정은 프로젝트 내부 좌표 처리 코드로 작성했고 제조사 판서 엔진·알고리즘·자산을 복제하지 않음
- 속도 적응형 저역 통과 필터는 일반적인 신호 처리 원리로 독자 구현했으며 외부 구현 코드를 복사하거나 포함하지 않음
- 화면 합성 주기 갱신과 픽셀 배율 계산은 WPF 및 Windows 공개 API만 사용함
- 둥근 창 외곽은 Windows DWM API를 사용하며, 미지원 환경에서만 GDI의 `CreateRoundRectRgn`/`SetWindowRgn`으로 대체함. 별도 배포물 없음
- Liquid Glass는 Windows의 공개 DWM 시스템 배경과 프로젝트 내부 색상·그라데이션 코드로 구현했으며 Apple의 이미지·아이콘·코드를 포함하지 않음
- 밝은 투명 리퀴드 글래스 재질은 프로젝트 내부 색상·그라데이션 값으로 직접 구성했으며 참조 이미지를 프로그램 자산으로 포함하지 않음
- 파스텔 굴절광 프리셋, 강화유리 외곽과 돌출 버튼은 WPF 기본 브러시·도형으로 직접 구현했으며 참조 이미지 자산을 포함하지 않음
- 패널 폭 조정과 오버레이 재생성은 프로젝트 내부 레이아웃·창 수명 관리 코드만 변경함
- 자료 조작 중 판서 표시와 입력 통과 분리는 WPF 및 Windows 공개 창 스타일 API만 사용함
- 팝업·트레이 글래스모르피즘은 WPF·Windows Forms·DWM 기본 기능으로 직접 구현함
- 완전 투명 패널과 굵기 적응형 필터도 기존 Windows/.NET API와 프로젝트 내부 코드만 사용함

현재 변경 사항에서 확인된 외부 저작물 재배포 요소는 없음.

## 향후 반영 기준

다음 중 하나라도 불명확하면 해당 자산이나 기능을 배포본에 넣지 않음.

1. 원저작자와 원출처
2. 수정·재배포 허용 여부
3. 프리웨어와 소스 공개 배포의 호환 여부
4. 저작자 표시와 고지 의무
5. 상표·특허·제품 외관 모방 가능성

외부 구성요소가 꼭 필요하면 사용 전에 라이선스를 확인하고 `THIRD_PARTY_NOTICES.txt`에 이름, 용도, 출처, 라이선스와 고지문을 기록함.

이 문서는 개발 단계의 점검 기록이며 법률 자문을 대신하지 않음.
