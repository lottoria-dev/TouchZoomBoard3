# TouchZoomBoard3 3.0.2 최종 검증 기록

검증일: 2026-09-08

## 3.0.0 제공 필기 기록 분석

| 항목 | 결과 |
|---|---:|
| 완료 획 | 30 |
| 취소 세션 | 26 |
| 도구 | 펜 29회, 형광펜 1회 |
| 입력률 | 보고 평균 185.8Hz, 일반 완료 획 약 149.5~191.4Hz |
| 하드 클램프 | 0회 |
| 끝단 이징 | 완료 획마다 1점 |
| 끝단 잔여 보정 | 평균 0.107 DIP, 최대 0.582 DIP |
| 재앵커 | 0회 |
| 소프트 제한 | 638회 |

`softLimits`는 필터가 지연 경계에 연속적으로 접근한 횟수이며 오류가 아닙니다. 하드 클램프와 재앵커가 없고 끝단 잔여 보정이 125% DPI에서 물리 1픽셀보다 작으므로 `adaptive-v8` 계수는 유지했습니다.

취소 26회 중 22회는 `unexpected-new-stylus-down`이며 모두 1~2패킷의 짧은 접촉 분절이었습니다. 나머지는 전체 지움 2회, Pen→Highlighter 1회, Line→Pen 1회였습니다. 이전 입력과 연결하지 않고 안전하게 초기화되는 동작으로 확인했습니다.

제공 기록의 배율은 모두 100%이므로 150~300% 필기는 Windows 실제 장치에서 별도 확인해야 합니다.

## 반영 사항

- 패널 바깥 림을 0.62 DIP, 안쪽 입사광·음영을 약 0.32 DIP로 축소하고 굴절광 알파를 절반 이하로 조정
- 패널 국부 반사광 폭과 밝기를 낮추되 버튼 외곽·터치 영역은 유지
- 3.0.1에서 적용한 짧게 누르기·길게 누르기 겸용 버튼의 12 DIP 이동 허용치 유지
- 3.0.1의 직선→펜 전환 터치 보정 유지
- 필기 필터 `adaptive-v8` 유지
- 일반 글자 굵기와 벡터 아이콘 선 굵기 하향
- 아이콘 픽셀 스냅 해제
- 굴절광이 패널 표면·가장자리·반사광·버튼에 함께 적용되는 구조 유지
- 로그 파일 생성 코드와 트레이 진단 메뉴 제거
- 표시 버전, 문서, 홈페이지와 GitHub Actions를 `3.0.2`로 통일

## 정적 검증 범위

- C# 소스의 괄호·문자열·전처리기 구조
- 프로젝트·설정 XML 파싱
- GitHub Actions YAML 파싱
- 홈페이지 HTML 파싱과 내부 앵커
- 공개 문서 상대 링크와 버전 문자열
- 로그 파일 I/O 코드 부재
- 소스 ZIP 무결성과 SHA-256

## 미수행 항목

현재 환경에 .NET Framework 4.8 WPF용 MSBuild와 Windows GUI·터치 장치가 없어 `Release / x64` 컴파일, 실행, 시각 비교와 전자칠판 입력 시험은 수행하지 못했습니다. GitHub 공개 전 Windows runner에서 빌드하고, 실제 전자칠판에서 직선→펜 짧은 터치를 반복 시험한 뒤 `VALIDATION_GUIDE.md`를 완료해야 합니다.
