Windows x64 · v3.0.2

TouchZoomBoard3

전자칠판 앞에서 노트북으로 돌아가지 않고 화면 확대·자료 조작·판서를 직접 사용하는 무설치형 수업 보조 프로그램입니다.

TouchZoomBoard3 3.0.2 다운로드

Windows 10/11 x64 · .NET Framework 4.8 · 무설치형 프리웨어

권장 ZIP 다운로드 릴리스 노트
TouchZoomBoard3_3.0.2_Windows_x64.zip
Portable · 설치 프로그램 없음

3.0.2 정식 릴리스: 필기 끝단 돌출을 완화하고, 선택한 굴절광이 패널과 버튼에 더 분명하게 보이도록 강화유리 표현을 조정했습니다. 아이콘과 글자의 체감 굵기를 낮추고 전자칠판의 도구 전환 터치 허용 범위도 보정했습니다.

실행 전 확인: 개인 개발자 프로그램으로 디지털 서명이 포함되어 있지 않아 Windows SmartScreen 경고가 나타날 수 있습니다.

공식 GitHub Release에서 내려받고 같은 Release에 제공되는 SHA-256 파일과 파일 이름을 함께 확인하세요.

01

수업 중 빠른 사용

수업을 시작할 때 필요한 네 단계입니다.

STEP 1

작은 패널 열기

프로그램을 실행한 뒤 화면의 작은 터치 패널을 눌러 전체 도구 패널을 엽니다.

STEP 2

빠르게 확대

상단 배율 버튼을 짧게 눌러 저장한 기본 배율로 확대합니다. 길게 누르면 100~500% 목록이 열립니다.

STEP 3

조작·판서

확대 화면은 바로 조작하고, 미니맵으로 확대 영역을 옮깁니다. 좌우 화살표로 필기·지우기·조작 메뉴를 전환합니다.

STEP 4

수업 화면 복귀

수업 화면 종료를 누릅니다. 화면이나 입력이 비정상적이면 Ctrl+Alt+Shift+Esc로 긴급 복구합니다.

02

개발 목적

노트북과 전자칠판을 HDMI 화면 복제 및 USB Touch 케이블로 연결한 수업 환경을 중심으로 개발했습니다. 교사는 전자칠판 앞을 떠나지 않고 작은 글씨, 도형, 표와 이미지를 확대하고 자료를 조작하거나 바로 판서할 수 있습니다.

구형 연속 터치 호출 방식은 웹문서 선택 동작과 충돌할 수 있어 제거했습니다. v3.0.2는 마지막 입력 한 점이 튀어나오지 않도록 끝단 보정을 점진적으로 바꾸고, 여러 모니터에서 균일하게 보이면서 선택한 빛의 색이 분명한 투명 강화유리 패널을 제공합니다.

03

설치와 기본 설정

설치 프로그램 없이 압축을 풀어 실행하는 Portable 방식입니다.

  1. TouchZoomBoard3_3.0.2_Windows_x64.zip을 내려받아 원하는 폴더에 완전히 압축 해제합니다.
  2. TouchZoomBoard3.exe를 실행합니다. 같은 폴더의 안내·라이선스 파일도 함께 보관하는 것을 권장합니다.
  3. 작업 표시줄 오른쪽 시스템 트레이와 화면 위의 작은 터치 패널을 확인합니다.
  4. 패널을 오른쪽 클릭하거나 아이콘을 길게 누른 뒤 환경 설정에서 전자칠판, 기본 배율, 패널 유리판 농도와 굴절광 색상을 지정합니다.
  5. 필요하면 Windows 시작 시 자동 실행을 켭니다.

필수 환경: Windows 10 22H2 또는 Windows 11 x64, .NET Framework 4.8 이상

04

주요 조작 방법

작업 터치 또는 마우스 키보드
전체 패널 열기·접기 작은 패널 또는 전체 패널 상단 가운데 아이콘을 짧게 누름 해당 없음
빠른 확대·100% 복귀 상단 배율 버튼을 짧게 누름. 환경 설정의 기본 배율로 확대되며, 다시 누르면 100%로 돌아감 해당 없음
배율 직접 선택 상단 배율 버튼을 길게 누른 뒤 100~500% 중 선택 해당 없음
확대·축소 두 손가락 핀치. 패널·미니맵에서는 마우스 휠, 자료 조작 중에는 Ctrl+휠 Ctrl + 마우스 휠
확대 영역 이동 패널에 붙은 미니맵을 누르거나 드래그. 미니맵 위치 버튼으로 패널 위·아래 전환 해당 없음
자료 조작·스크롤 조작 메뉴의 자료 조작 버튼을 누른 뒤 기존 판서를 화면에 유지하면서 웹페이지·PowerPoint·GeoGebra 등을 직접 조작. 일반 휠은 문서 스크롤 프레젠터 입력은 기존 프레젠테이션으로 전달
필기 도구 전환 좌우 화살표로 필기·지우기·조작 메뉴를 순환하고 펜·형광펜·모양을 선택 Ctrl + Z: 마지막 판서 되돌리기
색상·굵기 도구 아래 색상 막대를 눌러 16색 팔레트 호출. 펜·형광펜은 길게 눌러 굵기, 모양은 짧게 눌러 종류·길게 눌러 테두리 굵기 선택 해당 없음
확대·필기 종료 수업 화면 종료 아이콘 또는 트레이 메뉴 사용. 현재 판서와 확대 세션을 함께 종료 Esc
긴급 화면 복구 트레이의 긴급 화면 복구 선택 Ctrl + Alt + Shift + Esc
환경 설정 패널 우클릭 또는 작은 패널·상단 가운데 아이콘 길게 누르기 해당 없음
05

v3.0.2 주요 기능

상호작용 라이브 줌

Windows Magnification API와 화면 합성 주기 갱신을 사용합니다. 비정수 배율도 실제 원본 픽셀 크기에 맞춰 표시하고, 자료 조작 모드에서는 확대된 요소를 직접 누르거나 끌 수 있습니다.

패널 결합 미니맵

확대 중 전체 화면의 위치를 작은 저알파 미니맵으로 확인합니다. 자료 조작 중에도 기존 판서를 표시하며 패널은 이동하는 동안 포인터를 따라 계속 보입니다.

밝은 투명 Liquid Glass

컨트롤 패널은 DWM 색상판을 쓰지 않는 픽셀 단위 투명 창입니다. 0%에서는 패널판과 외곽이 사라져 버튼만 표시되고, 100%에서도 뒤 화면이 선명하게 비칩니다. 넓은 면의 대각선 그라데이션을 없애 모니터별 밴딩을 줄였습니다.

파스텔 굴절광

중성·하늘·민트·라벤더·로즈·피치 프리셋을 고르거나 Windows 색상 팔레트에서 원하는 색을 직접 지정할 수 있습니다. 선택색은 패널의 옅은 균일 표면색, 상·좌측 굴절대, 하·우측 음영과 돌출 버튼에 함께 반영됩니다.

적응형 필기

실제 입력 간격·속도·펜 굵기에 따라 떨림을 보정합니다. 마지막 패킷은 SmoothStep으로 완만하게 마무리해 획 끝이 튀어나오는 현상을 줄였습니다. 굵은 펜 지연 축소와 8px 이상 압력 노이즈 억제도 유지합니다.

로그 파일 없는 정식판

오류 로그, 필기 진단 로그 또는 사용 기록 파일을 만들지 않습니다. 화면 이미지, 문서 내용, 실제 필기 좌표와 사용 통계를 수집하거나 전송하지 않습니다.

프레젠터 포커스 유지

패널과 판서 화면이 프레젠테이션의 키보드 포커스를 가져가지 않도록 구성해 프레젠터 입력을 계속 사용할 수 있습니다.

안정적인 종료와 복구

판서 화면을 세션 종료 때 완전히 정리해 재진입 잔상을 줄였습니다. 수업 화면 종료, Ctrl+Alt+Shift+Esc와 트레이 긴급 복구를 지원합니다.

06

수업 활용 예시

  • 교과서 PDF의 작은 수식이나 도형을 확대해 판서하며 설명할 때
  • GeoGebra의 점이나 웹페이지의 인터랙티브 요소를 확대 상태에서 조작할 때
  • PowerPoint 애니메이션이나 동영상의 특정 부분을 실시간으로 확대할 때
  • 미니맵으로 전체 자료의 위치를 확인하면서 필요한 영역으로 빠르게 이동할 때
  • 프레젠터로 슬라이드를 넘기면서 전자칠판 위에 강조 표시를 추가할 때

휠 조작 구분: 패널·미니맵과 화면 이동 모드의 휠은 확대·축소에 사용됩니다. 자료 조작 모드의 일반 휠은 문서 스크롤로 전달되며, Ctrl을 누른 채 휠을 돌리면 확대·축소됩니다.

07

문제가 생겼을 때

증상 확인할 사항
패널이 보이지 않음 시스템 트레이에서 컨트롤 패널을 켜고, 환경 설정에서 대상 화면과 패널 위치 초기화를 확인합니다.
확대가 시작되지 않음 상단 배율 버튼을 짧게 누르거나 길게 눌러 125% 이상을 선택합니다. Windows 확대 기능을 제한하는 전체 화면·보안 프로그램인지도 확인합니다.
확대 중 자료를 누르거나 끌 수 없음 조작 메뉴에서 자료 조작 버튼이 선택되어 있는지 확인합니다. 관리자 권한, 보안 화면, 일부 독점 전체 화면 프로그램은 Windows가 입력 전달을 제한할 수 있습니다.
미니맵에서 이동되지 않음 미니맵 안을 짧게 누르거나 표시 영역을 드래그합니다. 미니맵 위치 버튼으로 패널 위·아래 위치도 바꿀 수 있습니다.
화면이나 입력 상태가 이상함 수업 화면 종료 또는 Esc를 사용합니다. 해결되지 않으면 Ctrl+Alt+Shift+Esc 또는 트레이의 긴급 화면 복구를 사용합니다.
두 손가락 핀치가 작동하지 않음 전자칠판 드라이버에서 Windows 멀티터치가 활성화되어 있는지 확인합니다. 우선 상단 배율 메뉴 또는 패널 위 마우스 휠로 조작할 수 있습니다.
100% 핀치 후 다시 확대되지 않음 v3.0.2는 100% 복귀 후 60초 동안 줌 세션을 유지하므로 빠르게 다시 확대할 수 있습니다. 이후에는 자원을 회수하며 다음 확대 때 자동 재생성합니다.
판서 재진입 때 이전 화면이 잠시 보임 v3.0.2는 판서 오버레이를 제거한 뒤 해당 모니터를 다시 그립니다. 잔상이 계속되면 Windows 버전, DPI, 확대 배율과 재현 순서를 적어 제보합니다.
프로그램 자체를 종료하고 싶음 패널을 오른쪽 클릭하거나 시스템 트레이 아이콘을 오른쪽 클릭하고 TouchZoomBoard3 종료를 선택합니다.
