# TouchZoomBoard3 3.0.5

전자칠판에서 화면 확대, 자료 조작과 판서를 사용할 수 있는 Windows 수업 보조 프로그램입니다.

## 주요 기능

- 실시간 화면 확대·축소와 확대 영역 이동
- 확대 상태에서 지원되는 프로그램의 요소 누르기·끌기
- 확대 영역의 위치를 확인하고 이동하는 미니맵
- 펜, 형광펜, 지우개, 사각형·타원·원·선분·화살표 판서
- 도구별 색상과 굵기 선택
- 지우개로 지운 획·도형과 전체 지움의 되돌리기
- 패널 농도와 굴절광 색상을 조절하는 투명 유리 디자인
- 프레젠터 사용을 위한 포커스 반환과 긴급 화면 복구

## 지원 환경

- Windows 10 22H2 또는 Windows 11 x64
- .NET Framework 4.8 이상
- 전자칠판 사용 시 HDMI 화면 연결과 USB Touch 연결

장치·드라이버와 대상 프로그램에 따라 터치 및 확대 화면 조작 범위가 달라질 수 있습니다.

## 설치와 실행

1. GitHub Releases에서 `TouchZoomBoard3_3.0.5_Windows_x64.zip`을 내려받습니다.
2. 원하는 폴더에 완전히 압축 해제합니다.
3. `TouchZoomBoard3.exe`를 실행합니다.
4. 작은 런처를 눌러 패널을 엽니다.

업데이트할 때는 실행 중인 프로그램을 종료한 뒤 새 폴더에 압축을 풀어 사용합니다.

## 사용 방법

- 상단 배율 버튼으로 확대하고 좌우 화살표로 필기·지우기·조작 메뉴를 전환합니다.
- 펜·형광펜·모양 아래의 색상 막대로 색상을 선택합니다.
- 펜·형광펜 버튼을 길게 누르면 굵기를 선택할 수 있습니다.
- 모양 버튼은 짧게 눌러 종류를, 길게 눌러 테두리 굵기를 선택합니다.
- 패널이나 트레이 아이콘을 오른쪽 클릭하면 환경 설정과 종료 메뉴를 사용할 수 있습니다.
- 화면 복구가 필요하면 `Ctrl+Alt+Shift+Esc` 또는 트레이의 긴급 화면 복구를 사용합니다.

### 원 그리기

1. **모양 → 원 (중심에서 끌기)**을 선택합니다.
2. 원하는 중심에 펜·손가락을 대거나 마우스 왼쪽 버튼을 누릅니다.
3. 접촉을 유지한 채 원 둘레가 될 위치까지 끌고 놓습니다.

처음 누른 점이 중심으로 고정되며, 끄는 동안 크기가 바뀝니다. 기존 타원은 별도 도구로 사용할 수 있습니다. 단순 탭이나 아주 짧은 끌기는 도형으로 남기지 않습니다.

### 되돌리기

- 지우개로 지운 획·도형은 삭제 역순으로 하나씩 복구합니다.
- 전체 지움은 한 번의 되돌리기로 복구합니다.
- 복구 이력은 현재 판서 세션에서만 유지합니다. 세션 종료·긴급 복구·프로그램 종료 후에는 복원하지 않습니다.
- 다시 실행(Redo)은 지원하지 않습니다.

### 터치와 확대 화면 조작

자료 조작 모드는 두 손가락 확대·축소와 세로 스크롤, 화면 이동 모드는 이동·확대 제스처를 처리합니다. 여러 접점을 전달하는 장치에서 사용할 수 있으며 실제 동작은 연결 환경에 따라 달라질 수 있습니다.

여러 손가락이나 여러 사람이 동시에 필기하는 기능은 현재 지원하지 않습니다. 도형도 한 번에 한 개씩 그립니다. 확대 화면에서 모든 Windows 요소나 모든 프로그램을 조작할 수 있는 것은 아닙니다.

## 소스 빌드

Visual Studio 또는 Build Tools에서 `.NET 데스크톱 개발` 워크로드와 `.NET Framework 4.8 SDK/Targeting Pack`을 설치합니다.

`TouchZoomBoard3.sln`을 `Release / x64`로 빌드하거나 저장소 루트의 `build_release.bat`을 실행합니다. BAT는 앱과 자동 테스트를 빌드·실행하고, 성공하면 `dist`에 실행 파일·Windows x64 ZIP·SHA-256 파일을 생성합니다.

C/C++ 워크로드와 외부 NuGet 패키지는 필요하지 않습니다. 실제 전자칠판 입력과 프레젠터 동작은 사용 환경에서 확인해야 합니다.
