# TouchZoomBoard3 3.0.2

전자칠판 앞에서 화면 확대, 자료 조작과 판서를 직접 사용할 수 있는 Windows 수업 보조 프로그램입니다.

## 주요 기능

- Windows Magnification API 기반 상호작용 라이브 줌
- 확대 상태에서 웹·PowerPoint·GeoGebra 등의 요소 직접 조작
- 확대 영역을 확인하고 이동하는 패널 결합 미니맵
- 펜, 형광펜, 지우개, 사각형·타원·선·화살표 판서
- 입력 속도·선 굵기·확대 상태와 부드러운 끝단 이징을 반영한 `adaptive-v8` 필기 보정
- 패널 농도 0~100%와 배경이 선명하게 비치는 밝은 Liquid Glass
- 패널과 분리된 선명한 유리 버튼과 고대비 벡터 아이콘
- 중성·하늘·민트·라벤더·로즈·피치 및 사용자 지정 유리 굴절광
- 화면·USB 장치 변경과 절전 복귀 뒤 터치 장치 자동 재확인
- 프레젠터 포커스 유지와 실제 마우스·터치패드 이동 시 커서 복구
- 확대·판서 종료 잔상 억제와 `Ctrl+Alt+Shift+Esc` 긴급 복구

## 3.0.2의 변화

패널 외곽 굴절 레이어의 두께와 밝기를 낮춰 여러 줄의 테두리보다 얇고 부드러운 Glassmorphism 림으로 보이도록 조정했습니다. 버튼 테두리와 터치 영역은 그대로 유지합니다.

3.0.1에서 반영한 전자칠판 직선→펜 전환 보정도 유지합니다. 짧게 누르기와 길게 누르기를 함께 처리하는 버튼의 이동 허용치는 일반 버튼과 같은 12 DIP이며, 길게 눌러 두께 메뉴를 여는 동작은 그대로입니다.

3.0.0에서 실제 장치 필기 기록으로 검증한 `adaptive-v8` 끝단 이징, 강화유리 패널, 굴절광 개인화와 가벼운 아이콘 표현을 모두 유지합니다. 당시 완료 획 30개는 하드 클램프 0회, 끝단 잔여 보정 거리 평균 0.107 DIP·최대 0.582 DIP였습니다.

환경 설정의 굴절광은 패널의 옅은 균일 표면색, 방향성 가장자리, 국부 반사광과 버튼 재질에 함께 적용됩니다. 외곽은 흰 테두리보다 선택색의 강화유리 굴절로 보이도록 구성했고, 아이콘과 글자는 일반 굵기를 중심으로 조정했습니다. 넓은 면에는 단색 저알파만 사용해 대각선 밴딩을 줄였습니다.

정식판은 오류 로그와 필기 진단 로그를 포함해 사용자 PC에 로그 파일을 만들지 않습니다.

## 지원 환경

- Windows 10 22H2 또는 Windows 11 x64
- .NET Framework 4.8 이상
- HDMI 화면 복제와 USB Touch 케이블 방식 전자칠판 권장

## 사용 방법

1. `TouchZoomBoard3_3.0.2_Windows_x64.zip`을 완전히 압축 해제합니다.
2. `TouchZoomBoard3.exe`를 실행합니다.
3. 작은 런처를 눌러 패널을 엽니다.
4. 상단 배율 버튼으로 확대하고 좌우 화살표로 필기·지우기·조작 메뉴를 전환합니다.
5. 패널이나 트레이 아이콘을 오른쪽 클릭해 환경 설정, 긴급 화면 복구와 종료 메뉴를 사용합니다.

## 빌드

Visual Studio 또는 Build Tools에서 `.NET 데스크톱 개발`과 `.NET Framework 4.8 SDK`를 설치한 뒤 `Release / x64`로 빌드합니다. 저장소 루트의 `build_release.bat`은 `dist` 폴더에 실행 파일, Portable ZIP과 SHA-256 파일을 생성합니다.

C/C++ 워크로드와 외부 NuGet 패키지는 필요하지 않습니다.
